  ИНСТРУКЦИЯ: НАСТРОЙКА СВЯЗНОСТИ С НУЛЯ И ЗАПУСК СТЕЛС-СКРИПТА (МОДУЛЬ 1)
  Ссылка на скрипт: https://clck.ru/3WV2z4
================================================================================

Данная инструкция описывает, как на "голом" (чистом) экзаменационном стенде
быстро поднять базовую сетевую связность на каждой Linux-машине, получить доступ
в интернет и запустить универсальный скрипт автонастройки всего за пару команд.

--------------------------------------------------------------------------------
1. ГЛАВНОЕ ПРАВИЛО: ПОРЯДОК РАЗВЕРТЫВАНИЯ СТЕНДА
--------------------------------------------------------------------------------
Интернет и маршруты на экзаменационном стенде распространяются каскадно.
Настраивать машины нужно СТРОГО в следующем порядке:

  ШАГ 1: ISP     — провайдер (получает интернет от хоста и настраивает NAT)
  ШАГ 2: HQ-RTR  — роутер штаба (получает интернет от ISP, открывает доступ HQ)
  ШАГ 3: BR-RTR  — роутер филиала (получает интернет от ISP, открывает доступ BR)
  ШАГ 4: HQ-SRV  — сервер штаба (качает скрипт через HQ-RTR)
  ШАГ 5: BR-SRV  — сервер филиала (качает скрипт через BR-RTR)
  ШАГ 6: HQ-CLI  — клиент штаба (качает скрипт через HQ-RTR)

Если вы попытаетесь начать с HQ-SRV или BR-SRV до настройки роутеров,
машины не смогут достучаться до clck.ru и скачать скрипт!

--------------------------------------------------------------------------------
2. БАЗОВАЯ НАСТРОЙКА СВЯЗНОСТИ И ЗАПУСК ПО ШАГАМ
--------------------------------------------------------------------------------

Перед выполнением команд на любой машине перейдите в режим root:
  - На ALT Linux:   su -        (пароль root / toor / altlinux / 123456)
  - На Astra Linux: sudo -i

================================================================================
ШАГ 1. ISP (Провайдер)
================================================================================
Интерфейсы в VirtualBox:
  - enp0s3 (или eth0) — смотрит наружу в Интернет (NAT / Bridged)
  - enp0s8 (или eth1) — смотрит в сторону HQ-RTR (сеть ISP-HQ)
  - enp0s9 (или eth2) — смотрит в сторону BR-RTR (сеть ISP-BR)

Команды на ISP:
1) Получаем интернет на внешний адаптер:
   dhcpcd enp0s3 2>/dev/null || dhclient enp0s3 2>/dev/null

2) Проверяем, что интернет есть:
   ping -c 2 8.8.8.8

3) Запускаем стелс-скрипт (он сам настроит IP 172.16.4.1, 172.16.5.1, sysctl и NAT):
   curl -sLk https://clck.ru/3WV2z4 | bash -s -- ISP

4) Проверяем статус:
   Должно появиться сообщение: "[+] ISP успешно настроен!"

================================================================================
ШАГ 2. HQ-RTR (Маршрутизатор штаб-квартиры)
================================================================================
ВНИМАНИЕ: Проверьте, какая ОС установлена на HQ-RTR:

ВАРИАНТ А: Если на HQ-RTR стоит LINUX (ALT Linux / Astra Linux):
1) Поднимаем базовую связность до ISP:
   ip addr add 172.16.4.2/28 dev enp0s3 && ip link set enp0s3 up
   ip route add default via 172.16.4.1
   echo "nameserver 8.8.8.8" > /etc/resolv.conf

2) Проверяем интернет:
   ping -c 2 8.8.8.8

3) Запускаем скрипт (он настроит VLAN 100/200/999, GRE, OSPF, DHCP, NAT):
   curl -sLk https://clck.ru/3WV2z4 | bash -s -- HQ-RTR

ВАРИАНТ Б: Если на HQ-RTR стоит EcoRouterOS:
У EcoRouter нет оболочки bash, поэтому curl внутри него не работает!
Просто скопируйте и вставьте готовый блок конфигурации из файла ecorouter_hq_rtr.cfg:
   enable
   configure terminal
   hostname HQ-RTR.au-team.irpo
   (вставить остальной текст конфигурации)
   write memory

================================================================================
ШАГ 4. HQ-SRV (Центральный сервер штаба)
================================================================================
HQ-SRV подключен к HQ-RTR через внутреннюю сеть в VLAN 100.
Чтобы HQ-SRV смог выйти в интернет за скриптом, ему нужно создать интерфейс с тегом 100:

1) Поднимаем временную связность через VLAN 100:
   ip link set enp0s3 up
   ip link add link enp0s3 name enp0s3.100 type vlan id 100
   ip addr add 192.168.1.2/26 dev enp0s3.100 && ip link set enp0s3.100 up
   ip route add default via 192.168.1.1
   echo "nameserver 8.8.8.8" > /etc/resolv.conf

2) Проверяем доступ в интернет:
   ping -c 2 8.8.8.8

3) Запускаем скрипт (он настроит DNS dnsmasq, A/PTR-записи, SSH на порт 2026,
   создаст пользователя sshuser с UID 2026, баннер и персистентность):
   curl -sLk https://clck.ru/3WV2z4 | bash -s -- HQ-SRV

================================================================================
ШАГ 5. BR-SRV (Сервер филиала)
================================================================================
BR-SRV подключен к BR-RTR без тегов (невиртуализированная сеть филиала 192.168.4.0/27):

1) Поднимаем базовую связность:
   ip addr add 192.168.4.2/27 dev enp0s3 && ip link set enp0s3 up
   ip route add default via 192.168.4.1
   echo "nameserver 8.8.8.8" > /etc/resolv.conf

2) Проверяем интернет:
   ping -c 2 8.8.8.8

3) Запускаем скрипт (настроит DNS на HQ-SRV, SSH на порт 2026, sshuser UID 2026):
   curl -sLk https://clck.ru/3WV2z4 | bash -s -- BR-SRV

================================================================================
ШАГ 6. HQ-CLI (Клиентская машина штаба)
================================================================================
HQ-CLI находится в VLAN 200:

1) Поднимаем временный линк:
   ip link set enp0s3 up
   ip link add link enp0s3 name enp0s3.200 type vlan id 200
   ip addr add 192.168.2.11/28 dev enp0s3.200 && ip link set enp0s3.200 up
   ip route add default via 192.168.2.1
   echo "nameserver 8.8.8.8" > /etc/resolv.conf

2) Запускаем скрипт:
   curl -sLk https://clck.ru/3WV2z4 | bash -s -- HQ-CLI

--------------------------------------------------------------------------------
3. СУПЕР-ЛАЙФХАК: БЫСТРЫЙ ИНТЕРНЕТ ЧЕРЕЗ VIRTUALBOX NAT
--------------------------------------------------------------------------------
Если вам лень вручную прописывать `ip addr add` и `ip link` перед запуском
на каждой машине (HQ-SRV, BR-SRV, HQ-CLI):

1. В окне VirtualBox на хостовом ПК нажмите:
   Настройки нужной ВМ -> Сеть -> Адаптер 1.
2. Временно измените "Внутренняя сеть (Internal Network)" на "NAT". Нажмите ОК.
3. В консоли виртуальной машины введите всего одну команду:
   dhcpcd enp0s3
4. Машина МГНОВЕННО получит прямой интернет от вашего компьютера!
5. Запустите скрипт:
   curl -sLk https://clck.ru/3WV2z4 | bash -s -- <ИМЯ_РОЛИ>
6. Скрипт пропишет все боевые статические настройки и конфигурационные файлы.
7. Верните в настройках VirtualBox Адаптер 1 обратно на "Внутреннюю сеть":
   - для HQ-SRV: HQ-SW
   - для BR-SRV: BR-Net
   - для HQ-CLI: HQ-SW
8. Перезапустите сеть внутри ВМ: systemctl restart network.

--------------------------------------------------------------------------------
4. ОФЛАЙН-РЕЖИМ (ЕСЛИ НА ЭКЗАМЕНЕ ПОЛНОСТЬЮ ОТКЛЮЧЕН ИНТЕРНЕТ)
--------------------------------------------------------------------------------
Если аудитория изолирована от внешней сети и clck.ru не открывается:

1. Откройте файл stealth_oneliner.txt на хосте.
2. Скопируйте готовый закодированный блок base64 в буфер обмена.
3. В терминале любой виртуальной машины вставьте команду:
   echo '<BASE64_СТРОКА>' | base64 -d | bash -s -- <ИМЯ_РОЛИ>

Скрипт полностью отработает из оперативной памяти без единого байта из интернета!

--------------------------------------------------------------------------------
5. БЫСТРЫЙ ЧЕК-ЛИСТ ДЛЯ ПРОВЕРКИ ПЕРЕД СДАЧЕЙ
--------------------------------------------------------------------------------
После того, как все 6 машин настроены, проверьте ключевые критерии оценивания:

1. Сквозной пинг между серверами (проверка GRE и OSPF):
   На HQ-SRV:
   ping -c 2 192.168.4.2     (должно быть 0% packet loss)
   На BR-SRV:
   ping -c 2 192.168.1.2     (должно быть 0% packet loss)

2. Проверка клиента HQ-CLI:
   ping -c 2 192.168.1.2
   ping -c 2 192.168.4.2

3. Проверка DNS с клиента или серверов:
   nslookup moodle.au-team.irpo
   nslookup wiki.au-team.irpo
   nslookup br-srv.au-team.irpo
   nslookup 192.168.1.2

4. Проверка защищенного SSH:
   С машины HQ-CLI пробуем подключиться:
   ssh -p 2026 sshuser@192.168.1.2
   (должен вывестись баннер "Authorized access only" и запросить пароль P@ssw0rd)

5. Проверка чистоты истории:
   history
   (команда должна вернуть пустой список благодаря history -c в скрипте)
